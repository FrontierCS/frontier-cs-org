World Map

Given which of N countries share a border, colour a K by K grid so that two colours touch exactly when their countries are neighbours. Any such map is valid, and a smaller map scores higher.

Questions

What makes a problem open-ended?

Its checker accepts any valid answer and then measures how good it is. No known answer is optimal, so the reference marks a strong answer and not the end of the problem.

How is a problem scored?

Each problem has a reference worth 60 points: the human reference where the problem has one, and otherwise the objective value that earned 60 under the earlier rule. Up to the reference, the score follows the problem's own curve, set so that the reference earns 60. Beyond it, the score is 60 plus the natural logarithm of how many times better the answer is, capped at 100, so each further point takes an answer e times better. A model's score is the mean over problems.

What changed in version 1.1?

In version 1.0, many problems gave full marks to an answer that matched the reference, so an answer that beat it scored no higher. Version 1.1 sets the reference at 60 and keeps rewarding answers beyond it. It removes 8 problems that are solved or no longer tell models apart (64, 140, 179, 180, 181, 184, 185 and 228), which leaves 180. It also fixes evaluator errors, removes test cases in problems 23 and 303 that every answer passes or that no answer can score on, and repairs an input of problem 82. Problem 61 now asks for the schedule itself instead of its value, so version 1.1 leaves it out as well, for 179 problems. The version 1.1 results are agent runs, each model in its lab's official harness.

The version 1.0 leaderboards are kept as they were. Their scores use the earlier rule and cannot be compared with version 1.1.

How do the version 1.0 leaderboards differ?

In a single attempt, a model writes one program and that program is scored. An agent works in a sandbox through Harbor for up to 5 hours, can submit many times for feedback, and keeps its best score.

How do I run a problem?

Clone the repository and install it with uv sync. Score a solution of your own:

frontier eval algorithmic 0 your_solution.cpp

Or let an agent work on the problem:

uv run frontier harbor trial algorithmic 0 -a codex -m gpt-5.5

The test cases are public.
