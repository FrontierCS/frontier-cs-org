<section class="sec" id="problems">
  <h2>Problems</h2>
  <div class="probs">
    <article class="prob">
      <figure class="ptile"><canvas id="pktile" role="img" aria-label="A packing of 300 pieces tightening as a search runs"></canvas><figcaption id="pklabel"><b></b></figcaption></figure>
      <h3>Polyomino Packing</h3>
      <p>Pack every piece, rotated or reflected as you like, into the smallest rectangle. Every packing without overlap is valid, and the score is the share of the rectangle the pieces fill.</p>
      <div class="lk"><a href="https://github.com/FrontierCS/Frontier-CS/blob/main/algorithmic/problems/0/statement.txt" target="_blank" rel="noopener noreferrer">Statement</a><a href="https://github.com/FrontierCS/Frontier-CS/tree/main/algorithmic/problems/0/examples" target="_blank" rel="noopener noreferrer">Example solutions</a></div>
    </article>
    <article class="prob">
      <figure class="ptile"><canvas id="wmtile" role="img" aria-label="Two valid maps of the same 14 countries, the second much smaller"></canvas><figcaption id="wmlabel"><b></b></figcaption></figure>
      <h3>World Map</h3>
      <p>Given which of N countries share a border, colour a K by K grid so that two colours touch exactly when their countries are neighbours. Any such map is valid, and a smaller map scores higher.</p>
      <div class="lk"><a href="https://github.com/FrontierCS/Frontier-CS/blob/main/algorithmic/problems/6/statement.txt" target="_blank" rel="noopener noreferrer">Statement</a><a href="https://github.com/FrontierCS/Frontier-CS/blob/main/algorithmic/problems/6/chk.cc" target="_blank" rel="noopener noreferrer">Checker</a><span>Adapted from <a href="https://qoj.ac/download.php?type=statement&amp;id=13904&amp;ver=hr_hr" target="_blank" rel="noopener noreferrer">IOI 2025</a></span></div>
    </article>
    <article class="prob">
      <figure class="ptile"><canvas id="pmtile" role="img" aria-label="A hidden permutation of eight numbers uncovered query by query"></canvas><figcaption id="pmlabel"><b></b></figcaption></figure>
      <h3>Permutation</h3>
      <p>A permutation is hidden. Each query is a sequence, and the only answer is how many positions match. Any strategy that finds the permutation is valid, and fewer queries score higher.</p>
      <div class="lk"><a href="https://github.com/FrontierCS/Frontier-CS/blob/main/algorithmic/problems/2/statement.txt" target="_blank" rel="noopener noreferrer">Statement</a><span>Adapted from <a href="https://www.cambridge.org/core/journals/combinatorics-probability-and-computing/article/mastermind-with-a-linear-number-of-queries/3BCAC12ED935616D36871C12E10A2288" target="_blank" rel="noopener noreferrer">Mastermind with a linear number of queries</a></span></div>

<section class="sec" id="questions">
  <div class="faq">
    <h2>Questions</h2>
    <div class="fqlist">
      <details><summary>What makes a problem open-ended?</summary><div class="ans"><p>Its checker accepts any valid answer and then measures how good it is. No known answer is optimal, so a score of 100 marks a strong reference and not the end of the problem.</p></div></details>
      <details><summary>How do the two leaderboards differ?</summary><div class="ans"><p>In a single attempt, a model writes one program and that program is scored. An agent works in a sandbox through Harbor for up to 5 hours, can submit many times for feedback, and keeps its best score.</p></div></details>
      <details><summary>How do I run a problem?</summary><div class="ans"><p>Clone the repository and install it with <code>uv sync</code>. Score a solution of your own:</p><pre>frontier eval algorithmic 0 your_solution.cpp</pre><p>Or let an agent work on the problem:</p><pre>uv run frontier harbor trial algorithmic 0 -a codex -m gpt-5.5</pre><p>The test cases are public.</p></div></details>
      <details><summary>Where are the research problems?</summary><div class="ans"><p>Research and repository-level tasks continue in <a href="{{ '/' | relative_url }}">FrontierCS 2</a>. This page covers the algorithmic problems.</p></div></details>
