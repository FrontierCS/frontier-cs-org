Metric definitions

Final score: accepted final evaluation. Pass/fail is an independent scientific criterion.

Best train: maximum verified training score. Never substitutes for the final score.

Run elapsed: wall time from run start, including startup, judging and cleanup. Curve time stops at each score event.

Tokens: provider-reported input + output across calls, including cached inputs where reported. Unknown usage stays unavailable.

Train / final: distinct train verification requests (including failed requests) / scored final evaluations. Curves contain only valid measured scores.

Public snapshot of verified formal results. Unpublished tasks are excluded from means and failure counts. Refresh checks the published snapshot.
